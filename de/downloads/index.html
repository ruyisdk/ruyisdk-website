RuyiSDK herunterladen

Laden Sie den RuyiSDK-Paketmanager und die IDE herunter und starten Sie Ihre RISC-V-Entwicklung.

Die passende Installationsmethode auswählen

Toolchains und Entwicklungsumgebung installieren

Der RuyiSDK-Paketmanager ist die zentrale Komponente von RuyiSDK. Er verwaltet Paketquellen, installiert Pakete, richtet virtuelle Umgebungen ein und bietet Anleitungen zum Flashen von Systemabbildern sowie Zugriff auf Neuigkeiten. Der Paketmanager selbst ist ein Kommandozeilenwerkzeug. Für den Einstieg und die Integration in bestehende IDE-Arbeitsabläufe bietet RuyiSDK außerdem ein Eclipse-Plug-in und eine Erweiterung für VS Code.

Das Eclipse-Plug-in und die VS-Code-Erweiterung enthalten einen Installer für den RuyiSDK-Paketmanager. Sobald das Plug-in oder die Erweiterung installiert ist, kann der Paketmanager in der Regel direkt aus der IDE eingerichtet werden. Die IDE-Integration wird weiterhin aktiv ausgebaut.

InstallationsmethodeVorteileNachteile
RuyiSDK-PaketmanagerVollständiger, stabiler FunktionsumfangBedienung über die Kommandozeile
VS-Code-ErweiterungGrafischer Arbeitsablauf in VS CodeFunktionsumfang wird weiter ausgebaut
Eclipse-Plug-inGrafischer Arbeitsablauf in Eclipse Embedded CDTFunktionsumfang wird weiter ausgebaut
Tipp

Der RuyiSDK-Paketmanager, die VS-Code-Erweiterung und das Eclipse-Plug-in laufen auch unter Windows und macOS. Der volle Funktionsumfang steht derzeit unter Linux zur Verfügung. Prüfen Sie vor der Installation die Plattformunterstützung für Ihr Zielsystem. Weitere Informationen finden Sie in der Dokumentation.

Ein Betriebssystem auf einem Entwicklungsboard installieren

Ruyi Imager ist ein grafisches Werkzeug zum Schreiben von Systemabbildern unter Windows, Linux und macOS. Die ersten Schritte finden Sie im Benutzerhandbuch.

Durch das Herunterladen und Verwenden von RuyiSDK stimmen Sie den Lizenzbedingungen und der Datenschutzerklärung zu.

RuyiSDK Paketmanager

Der RuyiSDK-Paketmanager ist die Kernkomponente von RuyiSDK und bietet Paketverwaltung sowie Umgebungs-Konfiguration.

Installationsskript (empfohlen)

Das Installationsskript erkennt Ihre Architektur, lädt die aktuelle stabile Version vom nächstgelegenen Spiegelserver herunter und installiert sie unter /usr/local/bin/ruyi:

bash
$ curl --proto '=https' --tlsv1.2 -fsSL https://ruyisdk.org/install.sh | sh

Für die Installation im eigenen Benutzerverzeichnis geben Sie das Zielverzeichnis ausdrücklich an:

bash
$ curl --proto '=https' --tlsv1.2 -fsSL https://ruyisdk.org/install.sh | sh -s -- --install-dir ~/.local/bin
