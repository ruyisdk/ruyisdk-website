RuyiSDK-Erweiterung für VS Code

Die offizielle Erweiterung für VS Code integriert den RuyiSDK-Paketmanager in die IDE. Damit lassen sich Toolchains installieren und aktualisieren, virtuelle Umgebungen erstellen, Neuigkeiten lesen und Quellpakete entpacken.

📄️ Funktionsübersicht

- Pakete. Ruyi-Pakete in der Seitenleiste von VS Code suchen, installieren und deinstallieren.

📄️ Installation

Voraussetzungen

📄️ Ruyi-Pakete verwalten

In der Ansicht Packages können Sie Pakete grafisch verwalten.

📄️ Virtuelle Umgebungen

Der Assistent der VS-Code-Erweiterung erstellt und verwaltet virtuelle Ruyi-Umgebungen für das Terminal und die Build-Werkzeuge.

📄️ Neuigkeiten und Statusleiste

Neuigkeiten

📄️ RuyiSDK-Quellpakete entpacken

Klicken Sie im VS-Code-Explorer mit der rechten Maustaste auf den Zielordner und wählen Sie Extract RuyiSDK Package, um offizielle Beispiele oder Quellpakete herunterzuladen und zu entpacken.

📄️ Projekte mit RuyiSDK bauen

Mit der Erweiterung können Sie Projekte per Mausklick bauen, Builds in einer virtuellen Umgebung (venv) ausführen und eigene Build-Regeln für Ihren Arbeitsbereich festlegen.

📄️ RuyiSDK-Beispiele und Board-Dokumentation

Wenn Sie neu bei RISC-V oder RuyiSDK sind oder ein Board schnell ausprobieren möchten, finden Sie in den RuyiSDK-Beispielen Anleitungen zur Einrichtung, Beispielprojekte und Tutorials zu Multimedia und KI. Sie können die Dokumente in Copilot öffnen, um Arbeitsschritte zu automatisieren.
