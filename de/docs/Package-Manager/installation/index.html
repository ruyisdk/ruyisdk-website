Installation

Vor der Installation
  • Mit dem Download und der Nutzung von RuyiSDK akzeptieren Sie die Lizenzbedingungen und die Datenschutzerklärung.
  • ~ bezeichnet das Home-Verzeichnis des angemeldeten Benutzers. Nutzen Sie bei Bedarf einen absoluten Pfad. Ersetzen Sie Platzhalter wie /home/foo durch Ihren tatsächlichen Pfad.
  • Die Installationsmethoden unterstützen unterschiedliche Betriebssysteme und Architekturen. Prüfen Sie vorab die Systemanforderungen im jeweiligen Abschnitt.

Für den RuyiSDK-Paketmanager stehen drei Installationsmethoden zur Verfügung:

  1. Vorkompilierte Binärdatei (empfohlen). Diese Methode unterstützt die meisten Plattformen und stellt die geringsten Anforderungen an das vorhandene System.
  2. Systempaketmanager. Verwenden Sie Werkzeuge wie apt oder yum, wenn Ihre Linux-Distribution das Paket ruyi bereitstellt.
  3. Python-Paketmanager. Wenn Sie bereits eine Python-Entwicklungsumgebung eingerichtet haben, können Sie pip verwenden.

Installation mit einer vorkompilierten Binärdatei

Unterstützte Systeme: Linux auf x86_64, arm64 und riscv64

Den RuyiSDK-Paketmanager herunterladen

Der RuyiSDK-Paketmanager ist für Linux als vorkompilierte Binärdatei für amd64 (x86_64), arm64 und riscv64 verfügbar. Die Binärdateien benötigen keine Python-Installation des Systems.

  • GitHub Releases
  • ISCAS-Spiegelserver

Prüfen Sie die Architektur mit uname -m. Wählen Sie unten die passende Architektur für den Download vom ISCAS-Spiegelserver aus.

Architektur auswählen:
$ wget https://mirror.iscas.ac.cn/ruyisdk/ruyi/tags/0.52.0/ruyi-0.52.0.amd64
Nach dem Download führen Sie bitte die folgenden Befehle basierend auf dem tatsächlichen Dateinamen im obigen Link aus (Befehle werden automatisch mit der Architektur aktualisiert):
$ chmod +x ./ruyi-0.52.0.amd64
$ sudo cp -v ./ruyi-0.52.0.amd64 /usr/local/bin/ruyi

Den RuyiSDK-Paketmanager installieren

Die oben angezeigten Befehle passen zur ausgewählten Architektur. Installieren Sie die Datei unter dem Namen ruyi in einem Verzeichnis in Ihrem PATH.

bash
$ ruyi version

Erscheinen die Versions- und Copyrightangaben, war die Installation erfolgreich. Prüfen Sie bei einer unerwarteten Ausgabe die Installationsschritte und die Systemumgebung.

Fehlerbehebung
  • Die installierte Datei muss ruyi heißen. Entfernen Sie einen etwaigen Architekturzusatz.
  • Stellen Sie sicher, dass die Datei ausführbar ist.
  • Prüfen Sie mit echo $PATH, ob das Verzeichnis mit ruyi im PATH steht.
Anderes Installationsverzeichnis
  • Ersetzen Sie /usr/local/bin im Installationsbefehl durch ein anderes Verzeichnis in Ihrem PATH.
  • ~/.local/bin ist ein geeignetes Verzeichnis für die Installation ohne Administratorrechte. Nehmen Sie es bei Bedarf in den PATH auf.

Installation mit dem Systempaketmanager

Arch Linux

Unterstützte Systeme: Arch Linux auf x86_64, arm64 und riscv64

Unter Arch Linux erleichtert der Systempaketmanager die Installation und Deinstallation von Ruyi. Die Verwendung des System-Python kann außerdem die Leistung verbessern.

Installieren Sie das Paket aus dem AUR als normaler Benutzer, zum Beispiel mit yay.

bash
$ yay -S ruyi

Wenn Sie das Arch-Linux-CN-Repository verwenden, können Sie den ISCAS-Spiegelserver eintragen.

ini
[archlinuxcn]
Server = https://mirror.iscas.ac.cn/archlinuxcn/$arch

Installieren Sie anschließend das Paket mit pacman.

bash
$ sudo pacman -Sy
$ sudo pacman -S ruyi

Gentoo Linux

Unterstützte Systeme: Gentoo Linux auf x86_64, arm64 und riscv64

Unter Gentoo können Sie den RuyiSDK-Paketmanager über das offizielle ruyisdk-overlay installieren.

  1. Installieren Sie eselect-repository und Git.

    bash
    $ sudo emerge --ask app-eselect/eselect-repository dev-vcs/git

  2. Stellen Sie sicher, dass das Gentoo-Hauptrepository eingerichtet ist. Normalerweise ist es bereits konfiguriert.

  3. Fügen Sie das Overlay hinzu.

    bash
    $ sudo eselect repository add ruyisdk git https://github.com/ruyisdk/ruyisdk-overlay.git

  4. Synchronisieren Sie das Repository.

    bash
    $ sudo emaint sync -r ruyisdk

  5. Akzeptieren Sie die Test-Keywords für das Ruyi-Ebuild. Erstellen Sie zunächst die nötigen Änderungen an package.accept_keywords.

    bash
    $ sudo emerge dev-util/ruyi --autounmask-write --autounmask

    Führen Sie dispatch-conf aus und übernehmen Sie die Änderungen mit u (use-new).

    bash
    $ sudo dispatch-conf

  6. Installieren Sie den RuyiSDK-Paketmanager.

    bash
    $ sudo emerge --ask dev-util/ruyi

  7. Prüfen Sie die Installation.

    bash
    $ ruyi version

Der Befehl gibt die Version und die Copyrightangaben aus. Prüfen Sie bei einem Fehler die Systemumgebung oder wiederholen Sie die Installation.

Installation mit dem Python-Paketmanager

Unterstützte Systeme: Linux auf x86_64 und arm64

Der RuyiSDK-Paketmanager ist auch auf PyPI verfügbar. Unter Linux auf x86_64 und arm64 können Sie pip oder pipx verwenden. Für RISC-V64 empfehlen wir die vorkompilierte Binärdatei.

Hinweis zu RISC-V

Einige Python-Abhängigkeiten von ruyi haben auf PyPI noch keine vorkompilierten Pakete für RISC-V. pip versucht daher, sie aus dem Quellcode zu bauen. Das kann lange dauern und scheitern. Verwenden Sie auf RISC-V nach Möglichkeit die vorkompilierte Binärdatei.

Wir prüfen die Verfügbarkeit der Abhängigkeiten regelmäßig. Wenn Sie die Installation mit pip dennoch ausprobieren, können Sie Ihre Erfahrungen in der chinesischen RuyiSDK-Community teilen.

Mit pipx installieren

pipx installiert Python-Kommandozeilenwerkzeuge in separaten Umgebungen und verlinkt ihre ausführbaren Dateien in den PATH.

bash
$ pipx install ruyi

Der Befehl ruyi ist anschließend über den PATH verfügbar, in der Regel unter ~/.local/bin.

bash
$ ruyi version

Wenn der Befehl die Copyrightangaben ausgibt, war die Installation erfolgreich. Prüfen Sie bei einem Fehler die Installationsschritte und die Umgebungsvariablen.

In einer virtuellen Umgebung installieren

Ersetzen Sie /path/to/some/venv durch den Pfad zu Ihrer virtuellen Umgebung.

bash
# Use the absolute path to your virtual environment.
# Replace the sample path with the actual path on your system.
$ /path/to/some/venv/bin/pip install ruyi

Die ausführbare Datei liegt im Verzeichnis bin der Umgebung und wird dem System-PATH nicht automatisch hinzugefügt. Nutzen Sie den absoluten Pfad oder aktivieren Sie die Umgebung.

bash
# Run ruyi using the full path.
# Replace the sample path with the actual path on your system.
$ /path/to/some/venv/bin/ruyi version

# Or activate the virtual environment first.
# Replace the sample path with the actual path on your system.
$ source /path/to/some/venv/bin/activate
$ ruyi version

Wenn die Copyrightangaben erscheinen, ist die Installation erfolgreich abgeschlossen.

Erste Schritte

Nach der Installation können Sie die integrierte Hilfe aufrufen oder mit der Dokumentation fortfahren.

bash
$ ruyi --help
