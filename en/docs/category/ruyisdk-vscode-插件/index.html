RuyiSDK VS Code Extension

The official VS Code extension brings the RuyiSDK Package Manager into the IDE. Install and update toolchains, create virtual environments, read news, and extract source packages.

📄️ Feature Overview

- Package Management: Browse, search, install, and uninstall Ruyi packages from the VS Code sidebar.

📄️ Virtual Environments

📄️ Extract RuyiSDK Package

In the VS Code Explorer, right‑click the target folder and select Extract RuyiSDK Package to directly download and unpack official examples or source packages.

📄️ Build a project with RuyiSDK

Use the extension to build a project in one click, run builds in a virtual environment (venv), or define build rules for your workspace.

📄️ RuyiSDK Examples and Board Documentation

If you are new to RISC-V or RuyiSDK, or want to try a board quickly, use RuyiSDK Examples to find setup guides, sample projects, and tutorials on multimedia and AI. You can open them in Copilot to automate parts of the workflow.
