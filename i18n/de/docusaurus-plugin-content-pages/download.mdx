## RuyiSDK-Paketmanager herunterladen

Ruyi bietet vorgefertigte Binärdateien für die Architekturen x86_64, riscv64 und aarch64 an.

### Installation mit dem Skript (empfohlen)

Das Installationsskript erkennt Ihre Architektur automatisch, lädt zuerst die neueste stabile Version vom ISCAS-Mirror herunter und installiert sie nach ``~/.local/bin/ruyi``:

<CodeBlock lang="bash" showTitleCopyButton="true" code={`
$ curl --proto '=https' --tlsv1.2 -fsSL https://ruyisdk.org/install.sh | sh
`} />

Für eine Installation in einem Systemverzeichnis führen Sie das Skript mit ``sudo`` aus und geben Sie den Installationspfad explizit an:

<CodeBlock lang="bash" showTitleCopyButton="true" code={`
$ curl --proto '=https' --tlsv1.2 -fsSL https://ruyisdk.org/install.sh | sudo sh -s -- --install-dir /usr/local/bin
`} />

### Manueller Download

Beim manuellen Download führen Sie ``uname -m`` aus, um die Systemarchitektur zu überprüfen, und laden Sie dann die entsprechende Binärdatei herunter.

<ArchSelector language="de"/>

:::tip
Falls die Seite den Download-Link nicht korrekt anzeigt, können Sie das [RuyiSDK-Mirror](https://mirror.iscas.ac.cn/ruyisdk/ruyi/releases/) besuchen, um die neuesten Binärdateien herunterzuladen. Alternativ finden Sie sie auch bei den [GitHub-Releases](https://github.com/ruyisdk/ruyi/releases).
:::

### RuyiSDK-Paketmanager installieren

Der obige Befehl wurde entsprechend Ihrer Architektur automatisch generiert. Stellen Sie sicher, dass die Binärdatei als ruyi installiert ist und sich in einem Verzeichnis befindet, das im PATH enthalten ist.

:::tip
Stellen Sie sicher, dass der Dateiname ``ruyi`` lautet.
:::

Führen Sie den folgenden Befehl aus, um die Installation zu überprüfen:

<CodeBlock lang="bash" code={`
$ ruyi version
`} />

Wenn der Befehl die Versions- und Copyrightinformationen ausgibt, wurde Ruyi erfolgreich installiert. Falls der Befehl fehlschlägt, überprüfen Sie Ihre Systemumgebung und wiederholen Sie die Schritte.

### Shell-Vervollständigung aktivieren

Fügen Sie den passenden Befehl in die Startdatei Ihrer Shell ein, etwa `.bashrc` oder `.zshrc`.

Für Bash:

<CodeBlock lang="bash" showTitleCopyButton="true" code={`
eval "$(ruyi --output-completion-script=bash)"
`} />

Für Zsh:

<CodeBlock lang="bash" showTitleCopyButton="true" code={`
#compdef ruyi
eval "$(ruyi --output-completion-script=zsh)"
`} />

## RuyiSDK-IDE herunterladen

Die RuyiSDK-IDE ist für x86_64, riscv64 und aarch64 verfügbar. Laden Sie das Archiv für Ihre Architektur herunter:

<CodeBlock lang="bash" code={`
$ wget https://mirror.iscas.ac.cn/ruyisdk/ide/0.0.3/ruyisdk-0.0.3-linux.gtk."$(uname -m)".tar.gz
`} />

:::tip
Aktuellere Versionen finden Sie auf dem [RuyiSDK-Spiegelserver](https://mirror.iscas.ac.cn/ruyisdk/ide/).
:::

### RuyiSDK-IDE installieren

Das folgende Beispiel installiert die IDE unter `/opt/ruyisdk`. Legen Sie zuerst das Zielverzeichnis an:

<CodeBlock lang="bash" code={`
$ sudo mkdir /opt/ruyisdk
`} />

Entpacken Sie das Archiv mit `tar` und `gunzip`. Passen Sie den Pfad zum heruntergeladenen Archiv bei Bedarf an:

<CodeBlock lang="bash" code={`
$ cd /opt/ruyisdk
$ sudo tar -zxvf ruyisdk-0.0.3-linux.gtk."$(uname -m)".tar.gz
`} />

Starten Sie die IDE:

<CodeBlock lang="bash" code={`
$ /opt/ruyisdk/ruyisdk/ruyisdk
`} />

Solange das RuyiSDK-IDE-Plug-in noch nicht in die IDE integriert ist, installieren Sie es separat:

+ Laden Sie das aktuelle Plug-in aus den [GitHub-Releases](https://github.com/ruyisdk/ruyisdk-eclipse-plugins/releases/) oder vom [RuyiSDK-Spiegelserver](https://mirror.iscas.ac.cn/ruyisdk/ide/plugins/eclipse/) herunter.
+ Folgen Sie den Installationshinweisen für die jeweilige Version in den GitHub-Releases.

### RuyiSDK-Erweiterung für VS Code installieren

Laden Sie die aktuelle `.vsix`-Datei aus den [GitHub-Releases](https://github.com/ruyisdk/ruyisdk-vscode-extension/releases) oder vom [RuyiSDK-Spiegelserver](https://mirror.iscas.ac.cn/ruyisdk/ide/plugins/vscode/) herunter. Wählen Sie in VS Code oder VSCodium **Install from VSIX...**.
