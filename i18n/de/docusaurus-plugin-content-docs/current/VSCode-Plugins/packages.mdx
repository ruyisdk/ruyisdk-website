# Ruyi-Pakete verwalten

In der Ansicht **Packages** können Sie Pakete grafisch verwalten.

- Pakete sind nach Kategorie gruppiert. Klappen Sie einen Paketnamen auf, um die verfügbaren Versionen zu sehen.
- Über die Symbolleiste können Sie nach Name und Kategorie filtern und die Liste aktualisieren.
- Installation und Deinstallation entsprechen der CLI. Der Status aktualisiert sich sofort. Ein grünes Häkchen kennzeichnet installierte Versionen.

![Paketansicht](@site/docs/VSCode-Plugins/image/image-5.png)

Paketquellen, Namen und Versionsregeln entsprechen der CLI. Weitere Informationen finden Sie beim [RuyiSDK-Paketmanager](../Package-Manager/index.md).

## Häufige Aufgaben

- **Toolchain installieren**. Wählen Sie die gewünschte Version, etwa von `gnu-upstream`, und klicken Sie auf die Schaltfläche zum Installieren.
- **Toolchain deinstallieren**. Wählen Sie bei der installierten Version die Aktion zum Deinstallieren aus.
- **Paketliste aktualisieren**. Nutzen Sie die Schaltfläche in der Symbolleiste oder den Befehl `Ruyi: Refresh Package List`.

Bei eingeschränktem Netzzugang richten Sie gemäß der [Installationsanleitung](../Package-Manager/installation.mdx) im Terminal einen Spiegelserver für Ruyi ein. Kehren Sie danach zur Erweiterung zurück und installieren oder aktualisieren Sie die Pakete.
