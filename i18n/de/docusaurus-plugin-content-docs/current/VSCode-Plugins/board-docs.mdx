# RuyiSDK-Beispiele und Board-Dokumentation

Wenn Sie neu bei RISC-V oder RuyiSDK sind oder ein Board schnell ausprobieren möchten, finden Sie in den RuyiSDK-Beispielen Anleitungen zur Einrichtung, Beispielprojekte und Tutorials zu Multimedia und KI. Sie können die Dokumente in Copilot öffnen, um Arbeitsschritte zu automatisieren.

## 1. RuyiSDK-Beispiele öffnen

Führen Sie `ruyi.board-docs` in der Befehlspalette von VS Code aus oder öffnen Sie **RuyiSDK Examples** auf der Startseite der Erweiterung. Die Funktion benötigt eine Internetverbindung.

## 2. Beispiele für ein Board ansehen

![Auswahl des Boards](@site/docs/VSCode-Plugins/image/image-12.png)

Wählen Sie das Board nach Marke und Modell aus. Die Board-Seite zeigt eine Übersicht und eine Liste der verfügbaren Beispiele.

![Verfügbare Beispiele](@site/docs/VSCode-Plugins/image/image-13.png)

Wählen Sie ein Beispiel aus. Die Anleitung zeigt, wie Sie es auf dem Board ausführen oder Aufgaben wie Multimedia-Verarbeitung, KI-Training oder Inferenz durchführen.

![Ein Beispieldokument](@site/docs/VSCode-Plugins/image/image-14.png)

Klicken Sie oben rechts auf **Open in VS Code**, um das Dokument mit dem zugehörigen Prompt an Copilot Chat zu übergeben.
