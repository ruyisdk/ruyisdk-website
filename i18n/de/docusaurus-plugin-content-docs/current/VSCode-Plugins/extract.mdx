# RuyiSDK-Quellpakete entpacken

Klicken Sie im VS-Code-Explorer mit der rechten Maustaste auf den Zielordner und wählen Sie **Extract RuyiSDK Package**, um offizielle Beispiele oder Quellpakete herunterzuladen und zu entpacken.

![Kontextmenü zum Entpacken](@site/docs/VSCode-Plugins/image/image-7.png)

## Ablauf

1. Legen Sie ein Arbeitsverzeichnis an und wählen Sie darin **Extract RuyiSDK Package**.
2. Wählen Sie das gewünschte Paket aus, etwa `coremark` oder `ruyisdk-demo`.
3. Folgen Sie nach dem Entpacken der README-Datei des Projekts, um es zu erstellen und auszuführen.

## Hinweise

- Installieren Sie die Toolchain zunächst unter **Packages**. Erstellen und aktivieren Sie anschließend eine virtuelle Umgebung, bevor Sie mit dem Build beginnen.
- Ein Beispiel finden Sie unter [CoreMark auf dem LicheePi 4A](./cases/case1.md).
- Die Erweiterung enthält keinen Flash-Assistenten. Beispiele zum Schreiben von Systemabbildern finden Sie in der Dokumentation des RuyiSDK-Paketmanagers.
