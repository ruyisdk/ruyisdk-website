# Ein Problem melden

Vielen Dank, dass Sie RuyiSDK verwenden. Wenn Sie auf ein Problem oder einen Fehler stoßen, eine Funktion vorschlagen oder Unterstützung für ein neues Paket wünschen, können Sie ein GitHub-Issue eröffnen oder einen Beitrag im Forum schreiben.

## Wo soll ich ein Issue eröffnen?

Die Komponenten von RuyiSDK liegen in verschiedenen GitHub-Repositories. Wählen Sie das passende Repository für Ihr Anliegen aus:

| Anliegen | Alle Issues ansehen | Neues Issue eröffnen |
| --- | --- | --- |
| Probleme mit dem RuyiSDK-Paketmanager, etwa unerwartetes Verhalten der CLI, Fehler bei der Installation, virtuellen Umgebungen oder beim Flashen von Geräten | [Issues ansehen](https://github.com/ruyisdk/ruyi/issues) | [Issue eröffnen](https://github.com/ruyisdk/ruyi/issues/new) |
| Defekte Paketlinks, veraltete Paketversionen oder Anfragen für neue Pakete | [Issues ansehen](https://github.com/ruyisdk/packages-index/issues) | [Issue eröffnen](https://github.com/ruyisdk/packages-index/issues/new) |
| RuyiSDK-Plug-ins für Eclipse | [Issues ansehen](https://github.com/ruyisdk/ruyisdk-eclipse-plugins/issues) | [Issue eröffnen](https://github.com/ruyisdk/ruyisdk-eclipse-plugins/issues/new) |
| RuyiSDK-Erweiterung für VS Code | [Issues ansehen](https://github.com/ruyisdk/ruyisdk-vscode-extension/issues) | [Issue eröffnen](https://github.com/ruyisdk/ruyisdk-vscode-extension/issues/new) |
| Oberfläche von ruyisdk.org | [Issues ansehen](https://github.com/ruyisdk/ruyisdk-website/issues) | [Issue eröffnen](https://github.com/ruyisdk/ruyisdk-website/issues/new) |
| Backend von api.ruyisdk.cn | [Issues ansehen](https://github.com/ruyisdk/ruyi-backend/issues) | [Issue eröffnen](https://github.com/ruyisdk/ruyi-backend/issues/new) |

Suchen Sie vor dem Eröffnen nach bestehenden Meldungen zum gleichen oder einem ähnlichen Problem. Ergänzen Sie bei einem identischen Problem die vorhandene Meldung um Angaben zu Ihrer Umgebung, Schritte zur Reproduktion oder andere Hinweise. Verlinken Sie bei ähnlichen Problemen die verwandten Issues in Ihrem Bericht.

## Welche Informationen gehören in das Issue?

Mit folgenden Angaben kann das Entwicklungsteam das Problem schneller analysieren:

1. **Umgebungsdaten**  
   Nennen Sie Software- und Betriebssystemversion, Hardwareplattform sowie weitere relevante Details. Geben Sie bei IDE-Problemen auch die Version von Eclipse oder VS Code an. Entfernen Sie sensible Daten wie Zugangsdaten, Kennwörter, Zugriffstokens und private Adressen.
2. **Problembeschreibung und Schritte zur Reproduktion**  
   Erklären Sie, was passiert ist, was Sie erwartet haben und mit welchen Schritten sich das Problem reproduzieren lässt. Fügen Sie relevante Fehlermeldungen, Protokolle oder Screenshots hinzu.
3. **Zusätzlicher Kontext**  
   Geben Sie bei Funktionsvorschlägen oder Paketanfragen den Anwendungsfall an. Bei einem Paket helfen der Projektlink und die gewünschte Version oder Zielplattform.

## Weitere Kontaktmöglichkeiten

Sie können auch in der [RuyiSDK-Entwicklercommunity](https://ruyisdk.cn/) oder in [GitHub Discussions](https://github.com/ruyisdk/ruyi/discussions) eine Diskussion beginnen.
