## Installation Script (Recommended)

The installer detects your architecture, downloads the latest stable release from the nearest mirror, and installs it to ``/usr/local/bin/ruyi``:

```bash input="1"
$ curl --proto '=https' --tlsv1.2 -fsSL https://ruyisdk.org/install.sh | sh
```

To install into home directory, run the script and pass an explicit install path:

```bash input="1"
$ curl --proto '=https' --tlsv1.2 -fsSL https://ruyisdk.org/install.sh | sh -s -- --install-dir ~/.local/bin
```
