## 使用说明

在电脑上用 Chrome 或 Edge 打开本页，准备一根可传输数据的 USB 线。刷写会覆盖目标分区，请先备份开发板上需要保留的数据。

1. **选择系统。** 在终端输入选项编号并按回车，依次选择开发板、硬件版本和系统镜像。遇到 `(y/N)` 时，输入 `y` 继续。
2. **准备镜像。** 点击“选择目录”。向导会校验 SHA-256，把刷写用的文件解包到所选目录的 `RuyiImages/` 下。如果提示手动导入，请按提示的完整文件名选择本地文件；需要下载时可使用侧栏提供的镜像链接。
3. **连接并刷写。** 让开发板进入 fastboot 模式，用 USB 线连接电脑，点击“连接开发板”并在浏览器中选中设备。核对刷写步骤和目标设备后再确认。保持 USB 连接，直到终端提示刷写完成。

遇到问题时，展开侧栏底部的“刷写日志”查看失败的步骤。如果向导提示镜像使用 `dd-v1`，请在本机运行 `ruyi device provision`。
