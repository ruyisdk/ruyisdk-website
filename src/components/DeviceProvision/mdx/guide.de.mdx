## Anleitung zum Flashen

Öffne diese Seite auf deinem Computer in Chrome oder Edge und verwende ein USB-Kabel, das Daten übertragen kann. Beim Flashen werden die Zielpartitionen überschrieben. Sichere vorher alle Daten auf dem Board, die du behalten möchtest.

1. **System auswählen.** Gib im Terminal die Nummer der gewünschten Option ein und drücke die Eingabetaste. Wähle so das Board, die Hardwarevariante und das Systemabbild aus. Bei der Abfrage `(y/N)` gib `y` ein, um fortzufahren.
2. **Abbilder vorbereiten.** Klicke auf **Verzeichnis auswählen**. Der Assistent prüft die SHA-256-Prüfsummen und entpackt die benötigten Dateien unter `RuyiImages/` im gewählten Verzeichnis. Wenn du eine lokale Datei auswählen sollst, achte auf den genauen Dateinamen. Falls du die Datei noch herunterladen musst, verwende den Download-Link in der Seitenleiste, sofern einer angezeigt wird.
3. **Board verbinden und flashen.** Versetze das Board in den Fastboot-Modus und verbinde es über USB mit dem Computer. Klicke auf **Board verbinden** und wähle das Board im Browser aus. Prüfe die angezeigten Schritte und das Zielgerät, bevor du das Flashen bestätigst. Lass das Board angeschlossen, bis das Terminal den Abschluss meldet.

Falls ein Schritt fehlschlägt, öffne das **Flash-Protokoll** unten in der Seitenleiste. Wenn der Assistent für ein Abbild `dd-v1` anzeigt, führe `ruyi device provision` auf deinem Computer aus.
